# Uizard Technologies

Uizard is an AI-powered UI design and prototyping platform that lets non-designers turn text prompts, screenshots, and hand-drawn sketches into editable mockups and multi-screen prototypes. Founded in Copenhagen out of the pix2code machine-learning research project, Uizard joined Miro in May 2024 and continues to operate as its own product.

Uizard publishes no public API, developer portal, or client SDKs — this profile captures the company's public web, legal, support, release-notes, and security surface, plus its GitHub organization and first-party open-source tooling.
